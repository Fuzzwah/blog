# Blog Project Spec

## Overview

Personal blog by Fuzzwah (Australian tech bloke) sharing learnings about agentic coding, AI-assisted development, tools, and workflows. Hosted on GitHub Pages with Jekyll at blog.fuzzwah.com.

## Tech Stack

- **Platform**: Jekyll static site generator
- **Hosting**: GitHub Pages
- **Domain**: blog.fuzzwah.com
- **Markdown**: Kramdown with Rouge syntax highlighting
- **Timezone**: Australia/Sydney

## Content Focus

Posts cover hands-on experience with:
- Agentic coding workflows and tools
- AI-assisted development (Copilot, Claude, MCP servers)
- VS Code extensions and configuration
- Developer tooling and automation
- Practical guides and migration stories

## Voice

All content follows `STYLE_GUIDE.md` — conversational Australian voice, technically detailed but never dry. The reader should feel like they're hearing about this stuff from a mate, not reading documentation.

## Post Structure

Each post is a markdown file in `_posts/` with YAML frontmatter (title, date, author, description). Posts use a mix of prose for narrative and lists/code blocks for technical content. Every post opens with a hook and closes looking forward.
